# 田旭鹏 (Erwin) — 个人介绍网站

一个纯静态、响应式的个人介绍网站，共 5 个页面：首页、学历、项目、荣誉、爱好。

## 页面结构

| 文件 | 页面 |
| --- | --- |
| `index.html` | 首页（个人信息 + 联系方式） |
| `education.html` | 学历介绍 |
| `projects.html` | 项目经验（当前为占位内容） |
| `honors.html` | 获得荣誉与证书 |
| `hobbies.html` | 个人爱好 |

## 如何预览

直接用浏览器打开 `index.html` 即可。若需要本地服务器，可以：

```
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

## 需要替换/补充的内容

### 1. 照片
把个人照片放到 `images/avatar.jpg`。照片放入后会自动替换首页的占位头像。建议长宽比约 4:5（如 800 × 1000）。

### 2. 项目经验（占位）
`projects.html` 里目前是 3 条示例占位卡片。打开该文件，把每个 `<article>` 里的
标题、时间、角色、技术栈和描述替换为你的真实项目（毕业设计、课设、个人作品、竞赛、实习项目等）。

### 3. 学校英文名 / 学位细节
`education.html` 中学校的英文译名可自行核对调整（当前为「白俄罗斯国立工业大学」的直译）。

## 技术说明

- 纯 HTML + CSS + 原生 JS，无任何外部依赖、可离线使用。
- 导航栏当前页面自动高亮（`js/main.js`）。
- 移动端有汉堡菜单；卡片有滚动进入的淡入动画（`.reveal`）。

## 自定义

- 配色与全局样式：`css/style.css`（`:root` 变量区）。
- 导航文案 / 页面高亮逻辑：`js/main.js`。
